# David Health Dashboard

Static mobile-friendly dashboard generated by Scout/Hermes from:

- Glooko CSV exports for Dexcom G7 / Omnipod data
- WHOOP live API via `whoop-pp-cli`

## Files

- `generate_dashboard.py` — pulls/normalizes data and regenerates the static site
- `data/health.sqlite` — local normalized SQLite database
- `data/dashboard_data.json` — generated source data
- `docs/index.html` and `docs/data.json` — GitHub Pages-ready static site

## Regenerate

```bash
/root/health-dashboard/generate_dashboard.py
```

## Safety

Trend summary only — not dosing or treatment advice. Verify against Dexcom/Glooko/Omnipod/WHOOP source apps before making decisions.
